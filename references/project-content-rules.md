# 用户提供的完整项目规则

## 使用身份

以下内容来自用户在建立爆款剧本工作流时提供的“爆款经验文本”。它必须参与选题、三个例子、大纲、正文和审核，但属于项目级创作约束，不等同于已核实的平台官方政策。

- “5月18日新规”“未公开隐性红线”“S级/A级/B级/C级扶持力度”“额外20%分账”“保底或上限播放量”等均为用户提供的说法。
- 未经当前官方来源核实，不得对外声称这些数字、日期和规则真实有效，也不得承诺过审、流量或收益。
- 用户明确要求按这套内部标准创作时，按更严格的一侧执行；用户的新要求与本文件冲突时，先指出冲突并以用户最新明确选择为准。

## 核心原则

整剧价值观正向优先，全链路审核，严管与扶持并行。

## 一、绝对禁止题材

1. 灵异邪祟：冥婚、鬼宅、僵尸、道士捉鬼、现代法术、邪祟附身及封建迷信。
2. 极端复仇：赶尽杀绝、以恶制恶、私刑或暴力复仇为主线。
3. 拜金神豪：有钱至上、炫富攀比、不择手段求财、夸张财富、一夜暴富、隐藏富豪和扮猪吃老虎。
4. 霸总虐恋：性别物化、强制爱、PUA、畸形婚恋、美化出轨或家暴、多角恋和情感操控。
5. 萌宝工具化：未成年人成人化、作为复仇或赚钱工具、参与成人商业和法律事务。
6. 现代修真：现代背景修仙、逆天改命、玄学改运、风水算命。
7. 历史虚无：歪曲重大历史、抹黑英雄烈士、恶搞经典IP、损害国家形象或民族团结。
8. 低俗擦边：暴露、色情、性暗示、低俗台词、封面或引流。

## 二、高风险题材

1. 豪门狗血、婆媳互撕、替嫁、多女主后宫、天价彩礼和阶级对立。
2. 复仇向重生，以及穿越真实历史并改变重大事件。
3. 带现代元素、法术万能或逆天改命的玄幻修仙。
4. 血腥恐怖、恶心猎奇、连环恶性犯罪和封建迷信式惊悚。
5. 过度放大职场阴暗、办公室政治或负面刻画公职人员。

采用高风险题材时，将目标从报复改为成长或澄清，将暴力改为证据、沟通、规则和责任，将绝望结局改为责任落实。

## 三、用户提供的S-A-B-C题材分级

### S级

- 乡村振兴：新农村、返乡创业、乡村旅游、农产品、乡村教育。
- 非遗文化：苏绣、剪纸、皮影、打铁花、唢呐、英歌舞、秦腔、昆曲等传承与创新。
- 现实主义：普通人奋斗、职场成长、家庭温情、邻里互助。
- 爱国主义：历史英雄、革命先烈、国家建设、科技报国、体育精神。
- 文旅融合：自然风光、人文景观、民俗和地方美食。

### A级

- 纯架空古风种田、女性传奇、武侠和智慧较量。
- 无血腥的都市悬疑、民国探案、盗窃诈骗、密室解谜等推理。
- 都市轻喜、职场日常、婚恋喜剧、邻里趣事和治愈。
- 纯架空科幻、未来、星际和奇幻冒险。
- 80/90年代市井、改革开放和吃苦耐劳型创业。

### B级

- 纯架空、无强制爱的古装言情。
- 无早恋、吸烟饮酒、暴力欺凌的青春成长、友情和校园活动。
- 萌宠拟人治愈轻喜。
- 尊重史实的历史科普。
- 体育竞技成长。

### C级

- 只辅助学习成长、不送钱或超能力的系统流。
- 改变悲剧、自我成长而非攻略角色的穿书。
- 不浪费、不暴饮暴食的美食内容。
- 动物保护、宠物日常和救援。
- 各行业职业故事与技能科普。

上述等级及扶持关系属于用户提供的内部分类，不能表述成已核实的官方等级。

## 四、六类零容忍内容

1. **不良价值观**：持续或极端侮辱、非人化羞辱、明显脏话、极端家庭暴力、错误伦理、暴力仇恨和犯罪教唆。
2. **低俗色情擦边**：暴露、性行为、性暴力、性暗示动作或台词、低俗封面和擦边变现。
3. **封建迷信**：鬼神、阴曹地府、现代法术、风水算命、占卜、星座运势和宗教元素商业化。
4. **观感不适**：极端血腥、伤害细节、恶心猎奇、恐怖画风，以及静态PPT式敷衍或粗制滥造。
5. **侵权与肖像滥用**：未授权AI换脸、动漫游戏素材、公众人物肖像、盗用剧本音乐、其他平台水印或备案号。
6. **未成年人及公序良俗**：未成年人早恋、烟酒、暴力欺凌、成人化；恶搞公众人物、损害国家形象、破坏民族团结或生硬蹭负面舆情。

## 五、鼓励方向

- 人物有成长线、结局积极、向善向美。
- 关注普通人生活与现实关怀。
- 传统文化与非遗传承。
- 独特视觉和叙事形式。
- 剧情连贯、逻辑自洽、画面和配音精品化。
- 独立自主的女性、积极向上的男性、有缺点也有行动的普通人。

## 六、用户提供的“隐性红线”说法

按本项目内部约束处理以下内容，但不得称为已核实的5月18日官方新规：

1. 禁止主角靠运气一夜暴富、突然获得超能力或让反派毫无还手之力的爽点碾压。
2. 禁止隐藏大佬、扮猪吃老虎、穷人实为富二代、被轻视者实为董事长等身份反转爽点。
3. 禁止用金钱、权力、美貌、手段、误会或试探操控感情。
4. 禁止未成年人帮助成年人处理职场、商业、法律或成人感情事务。
5. 医疗、法律和教育情节不得凭空下专业结论；涉及误诊、违法操作或体罚等内容时必须核实并谨慎处理。

## 七、用户提供的差异化审核尺度

- S级乡村、非遗和现实主义：允许适度困难与矛盾，但必须正向解决，避免抹黑群体和地域。
- A级古风、悬疑和年代：允许紧张与智慧较量，避免过度黑暗、血腥和真实重大历史篡改。
- B/C级言情、系统和穿书：用户给定的内部尺度偏严，倾向纯甜或成长，减少反派、误会和重挫折。

这不是可验证的通用平台规律。创作时同时考虑题材实际需要，不能为了“全程无冲突”破坏基本叙事逻辑。

## 八、用户提供的流量与扶持说法

原经验文本包含“S级保底100万以上”“A级优秀可达1000万并需申报”“B/C级自然流量上限100万”“S级额外20%分账”等数字。这些数字未经核实：

- 不写入剧本卖点或对用户作承诺；
- 不据此保证题材会成为爆款；
- 用户询问当前真实性时，必须查找明确平台的官方现行来源。

## 九、分类创作避坑

- 乡村：可以写返乡创业、带动产业和环境改善；避免把村干部、村民或城乡整体负面化；展示景色、美食和具体劳动。
- 非遗：展示真实技艺过程和传承；不赋予神秘力量，不用炫富作为回报。
- 现实主义：写普通人通过行动成长；可有可解决的困难，不把社会阴暗当卖点。
- 年代创业：还原年代物件、街道、服装和经营过程；不靠投机、关系、一夜暴富。
- 古风：使用纯架空背景；武侠突出侠义，权谋突出智慧，避免血腥和阴谋万能。
- 悬疑：重点表现推理和证据；弱化犯罪细节，结局落实责任。
- 古装言情：双向尊重、共同成长；禁止强制爱和性别物化。
- 校园：友情、学习、运动会和艺术节；不让未成年人承担成人剧情。
- 系统/穿书：系统只能辅助，结果来自主角努力；禁止送钱、超能力和碾压。

## 十、人物、剧情与台词通用约束

- 主角是有缺点但本质善良的普通人，通过劳动、学习、沟通、互助或责任担当成长。
- 对立者必须有现实利益和具体越界行为；不能只靠辱骂，也不能一句道歉免除责任。
- 女性角色保持独立目标，关键决定不能完全由男性代替。
- 冲突通过沟通、证据、规则、责任分担或合法途径解决。
- 项目原经验偏好线性成长并反对身份反转与碾压；允许有铺垫充分、揭露新因果的事实反转。
- 结局必须积极并落实事实和责任。原经验写有“大团圆”要求，但若强行和好会抹去伤害，可采用不复合、不团聚但边界清楚的正向结局；用户最新明确选择优先。
- 台词避免脏话、金钱至上、颜值至上和低俗热梗。
- 避免奢侈品、豪车豪宅和夸张财富特写；避免吸烟、饮酒、赌博以及把纹身、染发或服饰当作道德判断依据。
