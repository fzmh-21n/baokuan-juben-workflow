# 剧本格式与交付检查

## 格式选择

有爆款样本时，先按 [sample-alignment.md](sample-alignment.md) 提取文风与写作格式，并采用用户确认的样本格式。样本可以是第一人称自然短行、没有角色标签的叙述与对白；不得自动改成下面的标签格式，也不得额外套入样本没有的逐章起钩、固定收尾结构。

用户明确指定其他格式时，以用户要求为准；同一项目保持统一。固定音色可登记在外置设定表，不得用登记和标签撑正文长度。

## 无样本时的默认章节格式

仅在无样本或用户明确要求时采用：

```text
第1章：《章节标题》

新人物及固定音色

【人物】人物名：身份与关系。固定音色：音质、语速和情绪变化。

【场景】时代与地点时间

【角色】本场人物

【物品】关键物品 状态或摆放位置

【台词】人物名（固定音色。）（动作1+动作2+表情）：“对白。”

【台词】人物名（内心OS。）（可见动作+情绪变化）：“必要的内心信息。”

【本章字数】约XXXX字

【累计字数】约XXXX字
```

## 写作要求

- 有样本时，短句、叙述人称、对白呈现和动作表达跟随用户确认的样本文风；样本允许的独立叙述不视为格式错误。
- 无样本时，短句，多动作和对白，少景物描写；独立叙述尽量并入动作括号、对白或内心OS。
- 动作必须可视化，避免“十分难过”“气氛压抑”等无法直接表演的概括。
- 一条台词只承担一个主要意思；长解释拆成问答、打断或递进。
- 使用固定音色时首次登记，后续不得无故变化。
- 采用默认标签格式时，新人物只在首次出现章节登记；无新人物可写“本章无新人物”。样本正文没有此类登记时放到外置设定表。
- 关键物品必须参与剧情，不列无用摆设。

## 章节检查

每章完成后检查：

- 有章节标题时，是否符合已确认的样本标题方式；无样本时优先使用事件或悬念标题。
- 开头是否合理承接上文，结尾是否符合样本的段落与章节节奏；不强制每章独立起钩或制造新悬念。
- 本章是否完成一个不可替代的剧情功能。
- 是否出现已确认格式不允许的叙述或混用两种正文格式；不得把样本允许的叙述一刀切判错。
- 角色称呼、年龄和亲属关系是否一致；使用固定音色时同时核对音色。
- 按 [sample-alignment.md](sample-alignment.md) 核对完整事件数、主线数与关键事件的累计字数节奏，不能只对齐开头。
- 原创人物、地点、组织、店铺等专名是否与样本重名；所有原创专名必须另取新名。

## 字数口径

至少区分：

1. 标注字数：各章结尾人工标注值之和。
2. 正文中文字数：排除章节标题、人物介绍、场景、角色、物品和字数标签后，统计正文中的中文字符。默认标签格式包含台词行中的动作和对白；样本格式包含其叙述、对白与必要动作。
3. 纯对白中文字数：只统计真正说出的中文内容。默认标签格式可按引号识别；样本无引号时按其确认的对白识别方式核对，不得把叙述算作对白，也不得用空匹配冒充零对白。
4. 剧情正文可读字符数：用于样本节奏对齐，中文、字母、数字按单个字符计1，包含样本对应的叙述、对白和必要动作；排除标点、空白、章节抬头、人物与音色标签及检查说明。样本和原创必须使用同一口径，按此口径核对累计字数落点。

上述口径分开报告，不能把剧情正文可读字符数与正文中文字数、纯对白中文字数混比。无法可靠区分样本对白时说明限制，不填造统计值。

实测计数只用于核验正文、对白及样本节奏，不据此自行设定成品总字数、时长或章数。累计节点用于对照事件推进的位置与疏密，不变成总长硬配额，也不默认要求成品与样本总篇幅相同。

用户明确给出篇幅要求时，只记录并检查其实际指定的字数、时长、章数和统计口径，不补设其他目标。

## TXT交付

- 使用UTF-8编码；面向Windows普通文本工具时可使用UTF-8 BOM。
- 用户要求逐章保存时，每章一个TXT，文件名前置两位章节号保证排序。
- 用户要求合集时，按章节号排序合并，章节之间保留空行。
- 压缩包内只放用户要求的文件。交付前核对独立章节数、合集章节标题数和压缩包条目数。
- 最终回复提供可点击的绝对路径，并报告实际核验结果。
